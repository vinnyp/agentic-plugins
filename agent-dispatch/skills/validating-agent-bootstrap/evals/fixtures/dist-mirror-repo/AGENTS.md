# widget-dist — Agent Guide

This repo holds the **published build** of *widget*. Its contents are **generated** by widget's
release pipeline (`make publish`, run from the widget source repo): the committed binaries, the
packaged CLI, and the generated docs site. Releases are tagged `vX.Y.Z`.

The widget **source, tests, and design docs live in the widget repo** at `/path/to/widget-repo`.
